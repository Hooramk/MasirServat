# Hooranet VPN Manager — Android

نسخه 1.0 اولیه برای مدیریت فروش VPN روی گوشی اندرویدی، بدون هاست و بدون نیاز دائمی به اینترنت.

## امکانات
- رابط فارسی و راست‌چین
- دیتابیس داخلی SQLite
- ثبت نام مشتری، موبایل و Username
- نوع VPN و نام سرور
- تاریخ شروع و انقضا به صورت شمسی
- مبلغ و وضعیت پرداخت
- جست‌وجوی نام، موبایل، Username و سرور
- نمایش فعال / نزدیک انقضا / منقضی
- تمدید 1، 2، 3، 6 و 12 ماهه با نگهداری تعداد تمدیدها
- ویرایش و حذف مشتری
- پشتیبان‌گیری JSON و بازیابی اطلاعات
- آفلاین؛ اطلاعات روی خود گوشی نگهداری می‌شود

## ساخت APK
GitHub Actions روی شاخه hooranet-vpn-manager فایل APK را می‌سازد.

## امنیت
در این نسخه Password سرویس VPN ذخیره نمی‌شود و فقط Username و اطلاعات مدیریتی نگهداری می‌شود.
