# مسیر ثروت — Unity 3D Rebuild

این پوشه بازسازی سه‌بعدی مستقل بازی «مسیر ثروت» است. هدف، یک Life/City Simulator ایرانیزه با الهام از حلقه‌های گیم‌پلی بازی‌های شهری موفق است؛ نه کپی دارایی‌ها، کاراکترها، UI یا محتوای اختصاصی بازی دیگری.

## نسخه فعلی: Vertical Slice 0.1

وقتی پروژه را در Unity باز کنید و Play بزنید، صحنه به‌صورت Runtime ساخته می‌شود و شامل این بخش‌هاست:

- کاراکتر سوم‌شخص قابل حرکت
- دوربین دنبال‌کننده
- کنترل لمسی Landscape + WASD
- محله Low‑Poly با خانه، کافه، دانشگاه، بانک، فروشگاه، باشگاه، ملک کسب‌وکار و مرکز ارسال
- NPCهای متحرک
- تعامل نزدیک با دکمه «تعامل»
- شغل کافه با مینی‌گیم Timing سه‌راندی
- شغل پیک که بعد از خرید موتور باز می‌شود
- موتور قابل خرید و سوارشدن
- پول، انرژی، مهارت، اعتبار، پس‌انداز، بدهی و Level شغلی
- زنجیره مأموریت: اولین شیفت کافه → دانشگاه → بانک → خرید موتور → اولین کسب‌وکار
- کسب‌وکار با درآمد روزانه
- ذخیره خودکار با PlayerPrefs/JSON

## Unity

نسخه هدف: Unity 6000.6.3f1 (Unity 6.3 LTS)

## اجرا

پروژه را از پوشه Unity3D در Unity Hub باز کنید و صحنه Assets/Scenes/Main.unity را اجرا کنید.

صحنه عمداً خالی است. GameBootstrap در Runtime کل Vertical Slice را می‌سازد تا نمونه اولیه بدون Assetهای کپی‌شده یا فایل Scene پیچیده قابل توسعه باشد.

## کنترل‌ها

Desktop:
- WASD / Arrow Keys: حرکت
- E: تعامل
- R: پیاده شدن از موتور
- Space: توقف نشانگر در مینی‌گیم

Android:
- D-pad پایین چپ
- دکمه تعامل پایین راست
- دکمه Stop داخل مینی‌گیم

## Android Build

Build method: MasirServat.Editor.AndroidBuild.Build

خروجی: Builds/Android/MasirServat-Unity.apk

GitHub Actions برای Build آماده می‌شود ولی اجرای Unity در CI به credential/license معتبر Unity نیاز دارد. اطلاعات لایسنس نباید داخل repository commit شوند.

## مسیر توسعه بعدی

1. مدل و انیمیشن واقعی کاراکتر
2. Joystick آنالوگ و کنترل دوربین لمسی
3. Interior خانه/کافه/فروشگاه
4. Inventory، لباس و Appearance
5. خودروها و ترافیک
6. NPC relationship + dialogue
7. Quest chains چندمرحله‌ای
8. مشاغل بیشتر و کسب‌وکار قابل مدیریت
9. نقشه بزرگ‌تر تهران با محله‌های داستانی
10. Audio، VFX و polish موبایل

این شاخه برای جایگزینی Prototype جاوا ساخته شده و معماری آن از ابتدا Game-first است.
